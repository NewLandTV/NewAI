# NewAI 일상 대화 모델 선정 보고서

## 무엇을 어떻게 왜 바꿨나요?

| 후보 | What | How | Why / 결론 |
| --- | --- | --- | --- |
| 기존 UA 생성형 | 사전학습 없이 학습한 문자 단위 Transformer | UA-N1-Queen 808쌍, 학습 639쌍. 14회 중 검증 손실이 가장 낮은 10회차 | 자유 생성이 가능하지만 인사나 질문과 관련 없는 글자를 이어 붙이는 문제가 확인됨 |
| 확장 생성형 | 동일한 Transformer, 더 넓은 일상 대화 | 정제 후 6,002쌍, 학습 4,789·검증 614·테스트 599. 검증 기준 10회차 선택 | 자체 테스트 퍼플렉서티 10.94, 다음 문자 정확도 47.1%. 그래도 공통 질문에서 요청과 무관하거나 내용을 제안하지 못해 기본값에서 제외 |
| **최종 일상 대화 모델** | **답변 검색 + 낮은 확신일 때 재질문** | 합친 데이터의 학습 분할 4,789개 질문으로 TF-IDF 가중치를 추정. 43개 수작업 학습 문장과 10개 상황의 검수 답변을 사용. 문자 2~4그램 유사도와 상황 단서로 순위를 매김 | 글자를 새로 생성하지 않아 답변 자체가 깨지지 않음. 검증 동률에서 범위 밖 질문을 더 잘 보류한 후보를 선택. 대신 범용 지식과 다중 턴 기억은 제공하지 않음 |

UA 원본 800쌍과 Youngsook Song 일상 라벨 5,202쌍을 `user`/`assistant` 8개 JSONL로 합쳤습니다. 일상 외 라벨, 빈 행, 겹치는 질문, 반복 답변 등을 걸렀고, 확장 실험은 공백·문장부호만 다른 질문을 같은 분할에 넣습니다. 생성형은 문답 전체로 학습하지만 검색형은 공개 데이터 **질문**으로 표현 가중치만 학습합니다. 공개 데이터의 답을 그대로 서비스에 노출하지 않습니다.

### 선택 근거

수작업 검증 52개에서 의도 또는 올바른 보류를 맞힌 개수로 비교했습니다. 초기 파일의 `test` 묶음은 탐색에서 확인해 최종 검증으로 편입했으며, 최종 테스트는 별도 파일로 분리했습니다. 공개 말뭉치에서 검증·최종 테스트 질문과 정규화 문자열이 동일한 행은 가중치 추정에서 제외합니다.

| 검색 후보 | 검증 정답 | 범위 밖 보류 |
| --- | ---: | ---: |
| 문자 | 41/52 | 11/12 |
| 문자 + 단어 | 41/52 | 10/12 |
| **문자 + 상황 단서** | **47/52** | **12/12** |
| 문자 + 단어 + 상황 단서 | 47/52 | 11/12 |

각 후보에서 최소 점수와 1·2위 점수 차를 검증으로 골랐습니다. 최종값은 **0.36 / 0.02**입니다. 최종 별도 테스트에서는 **27/28 (96.4%)**: 범위 안 분류 19/20, 범위 밖 보류 8/8. 놓친 예는 `시험을 잘 봐서 기분이 정말 좋아요!`로, 기쁨 답변 대신 보류했습니다. 이 정확도는 **작고 직접 작성한 10개 의도 테스트**의 정답률입니다. 외부 사용자 대화의 만족도나 언어 모델의 다음 문자 정확도와 같지 않습니다. 생성형끼리의 퍼플렉서티도 서로 다른 분할과 문자 사전으로 계산했으므로 직접 비교하지 않습니다.

### 같은 질문으로 본 차이

아래 질문은 두 생성형의 학습·검증 데이터와 정규화한 질문이 동일하지 않습니다. 동일한 질문에 나온 실제 출력입니다.

| 질문 | UA만 생성 | 확장 데이터 생성 | 최종 검색 |
| --- | --- | --- | --- |
| 안녕하세요! 반가워요. 오늘 처음 인사해요. | 그래서 좋아~ 내가 다! | 응! | 안녕하세요, 반가워요! 오늘은 어떤 이야기를 해 볼까요? |
| 점심으로 빨리 먹을 수 있는 게 뭐가 있죠? | 그래서요! 좋아~ | 저 드세요. | 간단하게 먹고 싶다면 김밥이나 샌드위치는 어때요? 따뜻한 게 좋다면 국수나 덮밥도 괜찮아요. |
| 2026년 원달러 환율 알려 줘요. | 그래도 해요! 중이 시청자~ 시만들어요! | 응! 내가 옆에 있어요. | 지금은 그 질문에 맞는 답을 자신 있게 고르기 어려워요. 가벼운 일상 이야기를 하거나, 상황을 한 문장으로 다시 말해 줄래요? |

## 재현

```sh
python model/fetch_dataset.py
python model/prepare_daily.py
python model/daily_model.py train
python model/daily_model.py ask "점심 뭐 먹지?"
node --test test/daily-model.test.js
```

`model.json`과 `report.json`은 `checkpoints/daily-final/`에 생성됩니다. 같은 경로의 파일은 덮어쓰지 않습니다. 모델 파일에는 공개 말뭉치 원문 대신 가중치와 수작업 답변이 들어 있습니다. [다운로드 지침](../README.md#일상-대화-모델-받기)도 사용할 수 있습니다.

디스코드 연결에 쓰이는 로컬 전달 경로는 테스트했습니다. 실제 서버에서의 수신과 권한은 사용자가 테스트해야 합니다. `@NewAI 안녕!`, `@NewAI 점심 뭐 먹지?`, `@NewAI 내일 환율 알려줘`를 같은 서버 텍스트 채널에 보내면 각각 인사, 식사 제안, 보류가 기대됩니다. 봇을 멘션하지 않은 일반 채팅은 무시합니다.
